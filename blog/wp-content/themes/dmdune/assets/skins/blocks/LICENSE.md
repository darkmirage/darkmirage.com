# DarkMirage Blocks skin assets

The banners are the 2008 DarkMirage Blocks theme banners with the original lettering removed (the
lettering is now live text set in Jura). They are not covered by the theme's GPL: all rights
reserved by DarkMirage, and the characters shown (Hatsune Miku; Haruhi Suzumiya and Yuki Nagato;
Kallen Kozuki and C.C.) belong to their respective owners. `feed.png` is from the same theme.

assets/fonts/OFL-Jura.txt.
